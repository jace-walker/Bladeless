Blade, minus the line.

A face check-in for club events, built as an extension of Blade.

Our goal

Make checking in to Knight Hacks and Kickstart events take a second, with no QR code to find and no Discord login at the door.

Long lines at the start of an event are a small problem, but we run into it every time. Bladeless lets a member look at a camera, see “Hello, Name!”, and walk in. QR and manual check-in stay available as a backup, so nobody is ever stuck.

Why we built it

Opening Blade to pull up a QR code is easy to forget until you’re standing at the door, and then you’re signing in with Discord while the line grows. It isn’t the flashiest project, but it fixes something we all deal with.

How it works

  • Opt in once. A member agrees to a clear consent screen and takes five pictures with their webcam.
  • Look at the camera. A laptop at the door recognizes enrolled members and checks in several people at a time.
  • Organizers stay in control. An admin page manages members, dues, consent, events, and attendance.

Privacy comes first

  • Enrollment is strictly opt-in, and consent is required before any capture.
  • We store number embeddings that describe a face, never photos.
  • Members can withdraw consent or delete their face data at any time.
  • Dues status is shown only to organizers, never on the public screen.

What it’s built with

DeepFace with the Facenet512 model turns each face into a 512-number embedding. A Flask API on Vercel talks to Neon Postgres, where pgvector finds the closest match using cosine distance. The pages are plain HTML, CSS, and JavaScript styled to match Blade.

What’s next

Before this goes anywhere near a real club event, we want Knight Hacks leadership to review the privacy approach, add automatic deletion of face data after each event, and strengthen the check against someone holding up a photo.
